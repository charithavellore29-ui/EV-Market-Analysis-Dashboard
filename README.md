
# Electric Vehicle Market Analysis Dashboard

## Project Overview
An Electric Vehicle (EV) market analysis project developed using Microsoft Power BI to explore EV-related data and present insights through interactive visualisations.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX

## Project File
- `ETL EV.pbix` — Power BI dashboard and data model.

## Key Project Areas
- Electric vehicle market data analysis
- Data transformation using Power Query
- Data modelling and calculations using DAX
- Interactive dashboard visualisation

## Objective
To organise and analyse electric vehicle market data and communicate relevant insights through a Power BI dashboard.
